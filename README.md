# NEXOO Cloud

High-speed cloud drive integrating Cloud Play / Terabox 1TB storage with SSD-like performance on Apple Silicon.

## Features
- Ultra-fast local caching with LRU eviction
- Native macOS UI with Dark Mode support (#05070B background, #155BFF accent)
- Menu bar integration and status dashboard
- ARM64 optimized (no Rosetta dependency)
- Secure authentication for Cloud Play/Terabox
- Automated .dmg packaging pipeline
